## Discarded

Packets which are intentionally dropped by the networking component based on congestion, policy enforcement or resource constraints. This is a deliberate action by the device.

## Errored

Packets which become corrupted during transport, possibly due to physical layer issues. This can typically point to an issue with physical infrastructure or a hardware component issue.

### Giants

Packets exceeding the maximum Ethernet frame size. This can be tweaked with the MTU setting on the interface.

### Runts

Packets smaller than the minimum Ethernet frame size of 64 bytes. These can be caused by physical layer issues or congestion in the network.

### Cyclic Redundancy Check (CRC) Errors

Indicate corrupted data due to physical issues.
